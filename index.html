LifeCode

A simple voluntary personal code for basic demographic details

What is LifeCode?

LifeCode is a short voluntary code that combines several common personal details into one compact string. The goal is to make filling repeated information slightly faster when both sides understand the format.

Country + Sex + Age + Weight + Ethnicity + Marital Status + Blood Group

Example:

JPM4478ASB+

= Japan, Male, 44 years, 78 kg, Asian, Single, Blood group B+

Important: LifeCode is completely voluntary. You can skip any part you don’t want to share. It is not an official standard — just a convenient personal system anyone can use freely.

Format Details

Part Length Options
Country 2 ISO codes (IN, JP, US, GB, AU, etc.)
Sex 1 M = Male, F = Female, N = Non-binary/Other
Age 2 01–99
Weight 2–3 Weight in kg (whole number)
Ethnicity 1 A=Asian, W=White, B=Black, H=Hispanic, M=Mixed, O=Other, P=Prefer not to say
Marital Status 1 S=Single, M=Married, D=Divorced, W=Widowed, P=Partnered, U=Unspecified
Blood Group 2–3 A+, A-, B+, B-, AB+, AB-, O+, O-
